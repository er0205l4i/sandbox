# Kubernetes Debugging Notes

## Quick wins

- `kubectl get events --sort-by=.lastTimestamp` to see recent cluster events.
- `kubectl describe pod` still beats logs for scheduling/ImagePullBackOff issues.
- For crash loops, check `restartPolicy` and liveness probe timing.

## Observability

- Prometheus metrics: start with `rate(container_cpu_usage_seconds_total[5m])`.
- Alert on SLO burn rate, not just threshold breaches.
- Use `kubectl top nodes` as a first-pass signal, not a definitive answer.

## Useful aliases

```bash
alias k='kubectl'
alias kgp='kubectl get pods'
alias kd='kubectl describe'
alias kl='kubectl logs -f'
```
